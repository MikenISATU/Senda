# Deployer workspace blueprint
Create `ops/deployer/` with README, .env.example, .gitignore, deploy-testnet.sh, verify.sh, manifests/. The actual seed/private key must never be committed, copied into the PDF or added to .env.example. Store in a secure external secret manager, hardware-backed signer, or locked-down Stellar CLI identity, with distinct testnet and mainnet accounts. Testnet automated deployment may be configured with limited funded identity. Mainnet deployment, upgrades and custody movements require human authorization and audit checks. Log PUBLIC key, compiled WASM sha256, contract ID, network, tx hash, source commit, and release version, not secret material. Include testnet-to-mainnet dry-run checklist and rollback/pause procedure.
